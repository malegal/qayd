# واجهة مالك المكتب — الإصدار الثاني

## نطاق التعديل

أعيد تنظيم واجهة تطبيق قيد لمالك مكتب جاد الرب بحيث أصبحت لوحة التحكم والأجندة وبوابة المالك وإدارة القضايا صفحات مستقلة داخل التطبيق. لم تُحذف وظائف الملفات الإجرائية والخدمية أو مركز اعتماد الهاتف؛ أزيل فقط زر «الملفات القانونية» المكرر من صفحة إدارة القضايا لأن إنشاء الملف وإضافة مرحلة التقاضي موجودان داخل سير الملف نفسه.

## لوحة التحكم

تظهر لوحة التحكم عند الدخول وتعرض القضايا النشطة، جلسات اليوم والأسبوع، الجلسات المؤجلة، المهام المتأخرة، القضايا التي لا تملك جلسة قادمة، المتبقي من الأتعاب، والعمليات المحلية المعلقة. كما تعرض حالة الاتصال وآخر ملاحظات فريق المكتب، مع اختصارات لإنشاء قضية أو جلسة أو حدث أو فتح مركز اعتماد الهاتف.

## بوابة المالك

تتيح بوابة المالك رؤية عدد طلبات الهاتف وتعارضات المزامنة والمهام المفتوحة والإشعارات المحلية. وتوفر وصولاً مباشراً إلى دعوة أو عزل عضو المكتب، وقائمة أعضاء المكتب، ومركز اعتماد الطلبات والتعارضات، وقائمة المهام والملاحظات الحديثة. تظل صلاحيات الدعوة والعزل والاعتماد محكومة بدور مالك المكتب في طبقة Supabase الحالية.

## الأجندة

أصبحت الأجندة صفحة مستقلة. تعرض تقويم الشهر، وبجانبه قائمة مرتبة زمنياً بجلسات الشهر مع اسم العميل وكود القضية والمحكمة وحالة الجلسة. بقيت إضافة الأحداث والمهام وحاسبة المواعيد وإدارة الأحداث وتفاصيل اليوم كما هي، مع تحسين ترتيبها بصرياً.

## إدارة القضايا

أضيفت حالة القضية إلى نموذج الإنشاء والتعديل، بما في ذلك حالة «قيد الرفع». وأصبح نموذج تعديل القضية يعرض الحالة الحالية ويتيح إضافة عملاء أو خصوم إضافيين مع الصفة والهاتف وبيانات التوكيل ومكتب التوثيق. تحفظ الأطراف الجديدة محلياً وتدخل طابور المزامنة مثل بقية بيانات القضية. كما يظهر وضع القضية في بطاقة القائمة.

## التوافق والمزامنة

تستخدم الحقول الجديدة أسماء الحقول الموجودة في نموذج البيانات المحلي وسجل Supabase، ولا تتطلب تغييراً في بنية الجداول لأن `status` موجود ضمن نموذج القضايا الحالي. عمليات الأطراف الإضافية تستخدم `caseParties` و`upsert_case_party` الموجودة مسبقاً.

## التحقق

تم فحص JavaScript باستخدام `node --check` لملفات التطبيق، وفحص فروقات Git باستخدام `git diff --check`، وتحليل HTML بواسطة محلل Python، والتحقق من عدم تكرار معرّفات الصفحات والحقول الجديدة.
